## 🌟 Key Highlights & Features

- **Dynamic Hero & Profile Details**: Real-time introduction, target roles, academic credentials, and interactive contact modal.
- **Interactive Experience & Leadership Timeline**: Details on internships (EduTrack LMS, Internshala ISP) and 19+ university events coordinated.
- **Projects Showcase**: Interactive project catalog with live demos, code repositories, architecture highlights, and tech stacks.
- **Certifications & Skills Ecosystem**: Categorized technical competencies, cloud/industry certifications, and verified credentials.
- **Full-Stack Architecture**:
  - **Frontend**: React.js + Vite, TailwindCSS / Custom Modern CSS, Lucide Icons, responsive layout with smooth transitions.
  - **Backend**: Node.js & Express REST API with MongoDB / Mongoose support and active in-memory fallback.
  - **Interactive Contact Form**: Stores incoming visitor queries to database or memory with real-time feedback.

---

## 🛠️ Tech Stack

### Frontend
- **Framework**: [React.js](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Styling**: Modern responsive CSS / Glassmorphism / Dynamic animations

### Backend
- **Runtime**: [Node.js](https://nodejs.org/)
- **Framework**: [Express.js](https://expressjs.com/)
- **Database**: [MongoDB](https://www.mongodb.com/) via [Mongoose](https://mongoosejs.com/) (with robust in-memory fallback)
- **Utilities**: `cors`, `dotenv`

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### 1. Clone the Repository
```bash
git clone https://github.com/AdityaNayak13/PortFolio.git
cd PortFolio
```

### 2. Backend Setup
```bash
cd server
npm install
npm run dev   # Runs on http://localhost:5000
```

### 3. Frontend Setup
In a new terminal:
```bash
cd client
npm install
npm run dev   # Runs on http://localhost:5173
```
